# Konsou

An offline-first anime tracker for your own record. This is the rebuild.

The original app lives in `legacy/`. It is reference only: nothing in there is built or run. Pieces get pulled out one at a time, when the new app needs them.

The full old state is also tagged as `legacy-final`.

Privacy policy and terms: https://ashenvii.github.io/Konsou/privacy.html

See `OPEN.md` for what must not change and what is still undecided.
